# 屏幕识别工作台

在 Windows 上用本机 OpenCV、YOLO 和系统字形识别截图或手机实拍。工作台提供识别、学习和交付 AI 三个入口。

## 启动

```powershell
python -m pip install -r requirements.txt
python screen_ui.py
python screen_ui.py '图片路径.jpg'
```

检测权重和运行环境见 [本地检测模型说明](models/README.md)。

## 识别

点击「打开图片」或「粘贴截图」，工作台会自动识别当前画面。右侧「识别结果」列出控件编号和候选范围。点击列表或图中识别框，可以在原图定位控件并查看坐标。「重新识别」会再次处理当前图。

默认运行区域识别，保留候选框、前景遮罩、禁用状态和本机学习样本。用 `--full-analysis` 启动时还会扫读全页文字。点击「保存结果」可在选定目录保存一张标注 JPG 和一份页面 JSON。

页面 JSON 中的 `elements` 记录元素编号、范围与坐标，`layer` 记录当前前景。原图坐标从图像左上角起算，范围按左、上、右、下排列。有校准信息的实拍还会记录元素的毫米坐标。

## 学习

点击「学习」可以修改工作台框出的控件，也可以拖出新框补上漏识别的控件。拖动边角改变范围，拖动圆点调整点击位置，填写用途后保存。装饰或误识别区域可选「标为不可点击」。

在「学习 → AI 设置」填写支持图像输入的 OpenAI 兼容服务地址、模型名称和所需的 API 密钥。密钥仅用于本次运行，也可通过环境变量 `IMAGEPOSITION_AI_API_KEY` 提供。本地服务可留空。首次点「AI 补标」时也可以直接配置。

点击「AI 补标」后，工作台把当前画面的独立裁图和可用的 OCR 文字发给配置的模型。校验通过的结果会自动应用到当前图片，并作为 AI 样本写入学习库。已有人工标注优先，也可以随时拖框或修改用途。

工作台继续读取和更新本机已有的样本库 `%LOCALAPPDATA%\ImagePosition\control-examples.sqlite3`。用 `--examples` 可打开其他本地样本库。

## 交付 AI

点击「交付 AI」可直接查看交付 JSON 和每个编号对应的独立裁图。「复制附件」将本次预览的 `handoff.json` 和独立 JPEG 一起放入 Windows 剪贴板，可粘贴到支持文件附件的 AI 输入框。粘贴完成前保持工作台打开。「复制 JSON」可单独复制 JSON 文本。

JSON 记录当前前景、区域编号、原图范围及可见点位。有毫米标定时同时记录毫米点位和原点。局部图与 JSON 通过编号关联，可用的 OCR 文字随对应编号提供。

## 手机实拍与毫米坐标

用 `--phone-photo` 打开相机照片。程序定位发光显示区，做透视校正并据此识别控件，标注仍显示在原照片上。交付包使用校正后的局部图。线缆或夹具遮挡区域会参与可见性判定。

- 已标定的白色夹具实测宽 `90 mm`、高 `165 mm`。毫米原点是夹具左上角，X 向右，Y 向下。
- 更换机位或夹具时可用 `--screen-corners` 指定原照片中的显示区四角，按左上、右上、右下、左下顺序填写，每角两个像素值。加上 `--screen-size-mm` 传入发光显示区的实测宽高，毫米原点为屏幕左上角。

```powershell
python screen_ui.py '手机实拍.jpg' --phone-photo
python screen_ui.py '新机位.jpg' --screen-corners 270 259 922 251 917 1648 278 1650 --screen-size-mm 66 142
```

第二条命令中的坐标与尺寸为格式示例。使用时填入该照片的角点和屏幕实测宽高。

## 历史学习数据

历史训练清单、标注和素材保存在 `output/` 下各自原有的目录，`img/` 保存原有截图。工作台读取本机样本库 `%LOCALAPPDATA%\ImagePosition\control-examples.sqlite3`，清理前的备份在 `%LOCALAPPDATA%\ImagePosition\backups\`。
